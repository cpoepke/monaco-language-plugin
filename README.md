# monaco-language-plugin

LSP-backed code navigation for Monaco-based editors: Cmd/Ctrl+click go-to-definition
across files, find references, hover docs, document symbols and clickable links —
for TypeScript/JavaScript, Python, Go and Rust.

The first integration target is [Orca](https://github.com/stablyai/orca), the agent IDE.

> Work in progress. See `docs/` for design notes.
